# Update 7 September 2026

- Backend memeriksa event setiap 15 detik sejak server berjalan. Hanya SCHEDULED yang tanggal/jam mulainya sudah tercapai (WIB) menjadi ONGOING; DRAFT, CANCELLED dan COMPLETED tidak diubah. Daftar admin diperbarui setiap 15 detik dan saat kembali ke tab. Jam selesai tidak otomatis menyelesaikan workflow.
- Posisi guest baru: Tenda / Fotobox. Riwayat posisi lama dipertahankan.
- Tidak ada batas 366 hari untuk rentang jadwal. UI mengirim rentang per bulan secara berurutan dalam satu aksi. Biarkan halaman terbuka sampai selesai. Jika terputus, kirim ulang rentang sama: jadwal lama dilewati. Penyimpanan menggunakan batch 500 dan konflik dibaca dengan pagination.
- Kalender lintas tahun tetap dapat ditampilkan dan jadwal dibuat saat Google belum menyediakan data libur. Peringatan menunjukkan bahwa libur belum terverifikasi. Jadwal yang telah dibuat tidak otomatis dihapus saat data libur kemudian tersedia; tinjau dan edit sesuai kebutuhan. Minggu mengikuti hari kerja pilihan.
- Kalender Google memakai ID public-holidays Indonesia; konfigurasi ID lama yang mendapat 404 dicoba ulang memakai ID default. Error API tidak berarti tahun tersebut seluruhnya hari kerja. API key tetap harus valid dan Calendar API aktif.
- Crew Event tidak lagi melihat bonus/potongan/estimasi otomatis atau ekspor estimasi. Gaji pokok ditampilkan sebagai informasi, pembayaran akhir ditentukan finance. Crew Store dan perhitungan admin tidak diubah.

## Penerapan
Ganti source, install dependensi dari lockfile, build ulang frontend dan restart backend. Tidak ada migrasi SQL baru pada update ini; migrasi versi sebelumnya tetap diperlukan. Belum diterapkan pada server/database production.

## Validasi dan batas
Tes otomatis meliputi pergantian status tepat jam mulai WIB, kalender belum tersedia, rentang empat tahun termasuk 29 Februari, serta regresi keamanan. Pengujian produksi Google API dan database pengguna belum dilakukan. Tiga integration test database memerlukan konfigurasi lingkungan terpisah.

Referensi Google: https://developers.google.com/workspace/calendar/api/v3/reference/events/list dan https://support.google.com/calendar/answer/13748345 . Calendar API memakai rentang timeMin/timeMax; ketersediaan data libur ditentukan kalender sumber.
